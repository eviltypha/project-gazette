# Project Gazette

Citation-first Q&A service that answers compliance officers' KYC/AML questions **only** from
the synthetic RBI-style circulars in force on a given date, and refuses when the circulars do
not support an answer.

> Work in progress — sections below are filled in as each task lands.

## Layout

```
gazette/          Python package (ingest, retrieval, pipeline, API, eval, feedback)
data/circulars/   Synthetic circular corpus (committed)
eval/             Labelled eval set and generated report
tests/            Offline pytest suite (builds its own index in a temp dir)
index/            Generated by `python -m gazette.ingest` (git-ignored)
```

## Setup

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # optional; defaults run fully offline
```

## Run

```bash
python -m gazette.ingest
uvicorn gazette.api:app
```

## Tests

```bash
pytest          # offline, no API keys, no containers
```
